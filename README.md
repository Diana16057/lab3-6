# Квест «Особняк» — Лабораторная работа 3.6

Текстовый детективный квест, написанный на Python в рамках лабораторной работы.
Игрок исследует особняк, осматривает комнаты, находит улики и продвигается
к разгадке.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `mansion.py` | Игровая логика: комнаты, действия игрока, состояние игры |
| `main.py` | Точка входа: запускает игру и игровой цикл |
| `test_mansion.py` | Автотесты (pytest) для проверки игровой логики |

## Как запустить игру

Требуется Python 3.10+.

```bash
python main.py
